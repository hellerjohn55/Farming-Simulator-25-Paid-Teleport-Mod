Installation: Drop the entire zip into your mods folder for Farming Simulator 25

Why is it that a farmer just happens to have a teleportation machine? Even if a farmer did make one it wouldn't be free to run it. This mod makes using the teleport function cost money. There is a base fee no matter the distance and a per meter traveled fee. The cost is $251 from field 74 to 19 on riverbend springs. If you think this fee is too much or too little you can adjust it via the PaidTeleport XML in the mod settings folder. You can also adjust the minimum distance for it to count as teleportation, default is anything above 50 meters will be teleportation and incure a fee. I recommend using a mod like Quick Vehicle Select to be able to pick which vehicle you want to teleport to as if you cycle through the base game way it will charge you for each teleport.

FYI I did use Gemini to help me make this mod
